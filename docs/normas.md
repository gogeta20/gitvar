# Normas

Este archivo debe leerse al iniciar cada sesion de trabajo.

## Reglas actuales

1. Crear un archivo Markdown por sesion para documentar el progreso y las decisiones tomadas.
2. Guardar los archivos de sesion en `docs/sesiones/`.
3. Usar el formato `YYYY-MM-DD-sufijo.md`, donde el sufijo debe dar una pista breve del foco de la sesion.
